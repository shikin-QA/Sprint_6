# Sprint_6 — автотесты для Яндекс.Самокат

Учебный проект: автотесты на Selenium с Page Object Model и Allure-отчётом
для сервиса «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/).

## Что проверяется

- **Выпадающий список «Вопросы о важном»** — при клике на стрелку
  раскрывается соответствующий текст. 8 параметризованных тестов,
  по одному на каждый вопрос.
- **Заказ самоката** — полный позитивный сценарий с двумя наборами данных:
  - через верхнюю кнопку «Заказать» — 2 набора;
  - через нижнюю кнопку «Заказать» — 2 набора.
  - Проверяется: заполнение формы, появление окна об успешном заказе.
- **Логотипы** — переход на главную по логотипу «Самоката»,
  переход в Дзен в новой вкладке по логотипу Яндекса.


## Allure-отчёт

Сгенерировать данные и HTML-отчёт:

    python -m pytest --alluredir=allure-results
    allure generate allure-results -o allure-report --clean

Открыть отчёт в браузере:

    allure open allure-report

Готовый отчёт также хранится в репозитории — папка `allure-report/`.
